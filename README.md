# ホテル開発 初期評価デモ

物件情報を入力すると、初期評価で何が得られるかを説明するためのStreamlitモックです。

## デモで再現していること

- LANDまたは不動産仲介業者の物件概要書を入力する流れ
- 物件の基本情報を確認・入力する画面
- 建築ボリューム、ADR・稼働率、CFの出力イメージ
- 複数案件を比較した総合ランクと優先順位
- 次回ミーティングで確認すべき論点

## 重要

本デモは入出力と画面遷移を確認するためのモックです。表示される評価値は固定サンプルであり、OCR、スクレイピング、CF計算、決定木などの実処理は実装していません。

## 起動方法

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

ブラウザで `http://localhost:8501` を開きます。

## 入力

- 情報ソース
- 物件概要書PDF（任意）
- 案件名
- 所在地
- 土地面積
- 希望価格
- 想定ホテルタイプ
- 評価目的

## 出力

- 初期評価と総合ランク
- 建築ボリュームと想定客室数
- ADR、稼働率、RevPAR
- 売上、NOI、事業費、残余土地価格、IRR
- 候補案件内での優先順位
